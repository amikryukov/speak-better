# Практика речи — трекер

Одностраничное офлайн-приложение для ежедневной практики речи: **краткость и темп**, **словарный запас**, **теплота и юмор**.

## Как запустить

Данные хранятся в `localStorage`, поэтому для быстрой проверки на компьютере можно открыть `index.html` напрямую. Но офлайн-режим и установка приложения требуют **безопасного контекста** (HTTPS или localhost).

```bash
python3 -m http.server 8000
# на компьютере: http://localhost:8000 — localhost считается безопасным
```

Или любой статический хостинг (Netlify, GitHub Pages, Vercel и т.п.).

## Как добавить на телефон (Android)

Установка и офлайн-режим требуют **HTTPS**. Обычный `http://<IP-адрес-ноутбука>:8000` в локальной сети не считается безопасным — страница откроется, но сервис-воркер не запустится.

Выберите один из вариантов:

1. **HTTPS-хостинг** — Netlify, GitHub Pages, Vercel (проще всего).
2. **Chrome port forwarding** — телефон по USB, в `chrome://inspect` включить port forwarding на `localhost:8000`.

Затем:

1. Откройте страницу в Chrome на телефоне (по HTTPS-адресу).
2. Меню (⋮) → **«Добавить на главный экран»** / **«Установить приложение»**.
3. Приложение откроется как обычное — без адресной строки, с иконкой.

## Как работает трекер

- **Сегодня** — показывает упражнение на текущий день (определяется по дате) и кнопку «Готово». Один тап — и сессия записана.
- **История** — список выполненных сессий.
- **Ресурсы** — ссылки на материалы (видео, упражнения, книги) по трём направлениям.
- Сверху — **серия** (дней подряд) и **счётчик недели** (`выполнено/цель`).
- Цель по умолчанию — 3 сессии в неделю. Данные хранятся локально на устройстве.

## Как заниматься

- 10–15 минут, 3–5 раз в неделю, самостоятельно (запись себя, чтение вслух).
- Вечернее чтение книг — отдельно от практики: оно растит пассивный словарь.

## Напоминание

Импортируйте `practice-reminder.ics` в Google/Outlook-календарь — это повторяющееся событие 15 минут по понедельникам, средам и пятницам.

## Файлы

- `index.html` — приложение (разметка и стили).
- `src/core.js` — чистая логика (серия, неделя, ротация упражнений).
- `src/drills.js` — библиотека упражнений (15 шт., по 5 на направление).
- `src/resources.js` — ссылки на материалы.
- `src/main.js` — связка с DOM и `localStorage`.
- `manifest.webmanifest`, `sw.js` — PWA (офлайн, установка).
- `materials.md` — та же подборка материалов в текстовом виде.

## Тесты

```bash
node --test
```

Логика покрыта юнит-тестами (серия, неделя, ротация, чтение состояния).
